# products-storage — платные продукты и лид-магниты

⚠️ **Эта папка НЕ должна попадать в публичный корень сайта.**

При деплое содержимое переносится на сервер в закрытую папку **вне** webroot,
как указано в `SERVER-MANIFEST.txt` (рекомендуется `/products-marzhavbetone/`).
Прямые ссылки на платные архивы не публикуются — выдача покупателю выполняется
только после подтверждённой оплаты через обработчик заказа.

Файл `.htaccess` (`Deny from all`) в этой папке — страховка на случай, если
папка всё же окажется под Apache-webroot. Для nginx необходимо добавить в
конфиг запрет:

```nginx
location /products-storage/ { deny all; return 404; }
```

## Структура

- `00-free-*` — лид-магниты (3 шт., выдача бесплатно за контакт)
- `01`–`07` — платные комплекты Standard (выдача после оплаты)
- `build_*.py` — скрипты сборки комплектов в zip
- `SERVER-MANIFEST.txt` — карта соответствия комплектов и цен
- `README.md` — продуктовая стратегия v25.07.2026
- В каждом платном комплекте есть `00-PISMO-POSLE-POKUPKI.txt` — готовый
  текст письма для автоматической выдачи после оплаты
