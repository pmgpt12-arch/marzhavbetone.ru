**Версия:** 25.07.2026 (актуализированная после анализа конкурентов)

---

## Общая концепция

- **Лид-магниты** — собирают email/телефон, дают быструю пользу, ведут на триггер-продукты и платные комплекты.
- **Триггер-продукты** — микро-решения за 990–1 990 ₽. Снижают порог первой покупки.
- **Платные комплекты** — целостные системы действий. 3 уровня: Lite, Standard, Premium.
- **Полный комплект** — объединяет все платные продукты со скидкой.
- **Абонемент** — рекуррентный доступ ко всем продуктам + обновления + поддержка.

**Принцип названий:**
- Лид-магнит = формат + конкретная проблема.
- Триггер = конкретный результат + цена.
- Платный = «Результат для клиента» (не просто "шаблоны", а "взыскание задолженности").

## План действий

1. **P0 — Срочно:** Переименовать все продукты. Обновить обложки PDF.
2. **P0 — Срочно:** Добавить в лид-магниты сравнительные таблицы и превью платных.
3. **P1 — Важно:** Создать триггер-продукты T1–T3.
4. **P1 — Важно:** Обновить цены на сайте и в платёжной системе.
5. **P2 — Желательно:** Записать видеоразборы кейсов для Premium.
6. **P2 — Желательно:** Создать лендинги под каждый продукт.
7. **P3 — Перспектива:** Запустить абонемент A1/A2.
8. **P3 — Перспектива:** Решить судьбу 03 (включить в P6 / переделать / удалить).
