## Очередь атомарных задач

1. **P1 / калькулятор ст. 395:** только exact-SHA evidence → ограниченные расчётные тесты, если их действительно нет.
2. **P4 / Excel №44 v3:** только внешний вид печати после двух правок ширины; восстановление работы Office VM — инфраструктурная задача, не оправдание полной переработки XLSX.
3. **Наследование native evidence:** карта `current member SHA → prior receipt SHA → PASS / NOT_FOUND`. Новые проверки выполнять только для несовпадающих SHA там, где они обязательны.
4. **Юридические источники:** точечная матрица правовых утверждений/редакций/дат для текущих SHA. Не активировать пробный КонсультантПлюс до определения реального перечня недостающих документов.
5. **Покупательский E2E:** отдельный репрезентативный санкционированный сценарий оплата → письмо → действующая 3600-секундная ссылка → отрицательные 403/410. Не создавать фиктивных клиентов и не объявлять транспортный тест полной приёмкой содержания.

## Acceptance / ограничения

**Verified:** подтверждены 22 актуальных архивных продукта, их SHA/CRC и release evidence; для 11 бесплатных — `FULL_QA_PASS`. **Не проверено данной задачей:** полное юридическое/нативное QA всех 11 платных редакций, реальные платёжные E2E каждого SKU, Office #682 после восстановления. Никаких production-записей и новых тестовых покупок эта матрица не производит.

**Правило:** старый QA-13 на P1/20 не заменяет QA текущего P1/18; native receipt предыдущей версии применим только по неизменённому SHA. Любой отказ COM/tool классифицировать как runtime/harness/permissions до вывода о дефекте продукта.
