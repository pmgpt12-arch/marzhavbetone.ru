# Старые контакты НСП — проверенная очистка 30.10.2026

Статус: PASS_SCOPED_LEGACY_CONTACT_CLEANUP. Это результат конкретной очистки серверных контактных записей, не заключение о полном соответствии 152-ФЗ, не квитанция уведомления РКН и не подтверждение уничтожения всех данных во всех внешних системах.

## Подтверждённый результат

Владелец поручил удалить ненужные пользовательские данные прежнего сайта и подготовить уведомление по действующему сайту. Сначала выполнена инвентаризация, затем точный план с проверкой хешей и тесты на синтетических данных.

- Старый runtime: 18 записей с email, 15 с дополнительным контактом; 10 неоплаченных, 8 оплаченных по 100 копеек. Все 18 исходных контактных JSON удалены. В старом runtime таких записей осталось 0.
- 8 минимальных записей об оплаченных операциях сохранены в отдельном закрытом каталоге вне сайта (0700, файлы 0600). Сохранены дата, сумма, статус, идентификатор платежа, позиции; email, телефон, attribution, ключи статуса и блок выдачи исключены. Это минимизация финансовых сведений, не объявление полного обезличивания идентификаторов операций.
- Из двух резервных архивов удалены 36 копий старых записей. До атомарной замены проверена сохранность содержимого всех остальных членов архивов. Повторная проверка отсутствия целевых записей PASS. Новая резервная копия исходных контактов не создавалась.
- Проверены восемь областей резервирования. 39 оставшихся order JSON — подтверждённые технические migration_probe с provider_payment_performed=false, пустыми email и отсутствующим телефоном. Неидентифицированных копий заказов в обследованных областях не осталось.
- Удалены 20 старых ротированных журналов старого домена, два текущих журнала обнулены без изменения их владельца/прав и без отключения журналирования. Последующие запросы перенаправления могут создавать новые технические записи.
- Два JSON заказа нового сайта сохранены с исходными хешами. Все PHP обоих сайтов сохранены побайтно. Контроль главной нового сайта после операции — HTTP200.

## Что установлено по новому сайту

Найдены два оплаченных заказа по 1 ₽ от 21–23.10.2026 и три зарегистрированных скачивания. Это согласуется с известными тестами владельца; утверждение, что обработки на новом сайте ещё не было, использовать нельзя. Отдельного независимого подтверждения, что любой такой заказ принадлежит владельцу, эта очистка не выполняла. Данные действующего сайта по этому поручению не удалялись.

В общей локальной очереди аналитики найдены 1637 событий, включая 11 magnet_delivered; полей email/phone/contact/name в проверенном потоке не найдено. Это не доказывает полного обезличивания идентификаторов. Очередь общая, и достоверное разделение по доменам не установлено, поэтому её нельзя считать очищенной этой операцией.

## Ограничения и следующий этап

- Внешняя почта Яндекса не открывалась и не очищалась. Ранее обработчики направляли на служебную почту заявки с контактами; наличие/объём сохранившихся писем необходимо проверить отдельно.
- Управляемые провайдером резервные снимки не обследованы; физическое гарантированное стирание данных на носителях не заявлено. Выполнено логическое удаление в доступных файловых хранилищах и замена архивов.
- Сторонняя аналитика/кабинет Метрики и домашние копии общей очереди не очищались; контуры, не обследованные доступным каналом, не объявляются пустыми.
- Уведомление РКН не отправлено. Подготовлен отдельный проект полей; необходимы подтверждение адреса и контактов ИП, фактической даты начала/других целей обработки, адреса ЦОД и резервирования, получателей, оснований аналитики, сроков и трансграничной передачи. Официальный реестр/форма при чтении не открылись; отсутствие существующей записи не установлено.
- Удаление контактов и смена домена не обнуляют уже состоявшуюся обработку. Не указывать заведомо будущую дату начала вместо фактической.
