## Пилот PDF

Из действующего исходника P1 00-INSTRUKCIYA.docx через существующий экспорт LibreOffice подготовлен отдельный четырёхстраничный пилот: обложка, две исходные страницы инструкции и контакты для печати. Содержательные XML-узлы инструкции сохранены как подпоследовательность. Покупательские DOCX/PDF и архив P1 не изменены.

Колонтитул: лёгкий бренд, пять значков, номер страницы. У каждого значка отдельная ссылка. LibreOffice не сохранил ссылки на картинки колонтитула; завершающий этап экспорта восстанавливает только annotations из общего contacts.json, не переписывая текст и геометрию. На четырёх страницах 20 ссылок по значкам плюс пять текстовых ссылок последней страницы. Рендеры экрана и чёрно-белого представления проверены; фон ограничен внешним полем, вне таблиц и текста.

Пилот содержит /MarkInfo /Marked=true и /StructTreeRoot; annotation Contents заданы. Полнота семантических тегов и доступность порядка чтения не проверены. Унифицированных форм в выбранной инструкции нет; исходные рабочие формы не менялись. Массовое распространение только после согласования пилота согласно PDF-D из ТЗ. Внешние назначения проверяются отдельно в destination-probes.json; mailto не отправляет письма.

Три тематических мотива подготовлены встроенным image_gen только для просмотра (motifs/), в production не применены. Основа: светлая подложка, тонкие линии по правому краю, графит и золото; договор/согласование, работы/документация, оплата/споры.

Дзен: существующая на сайте пиктограмма из четырёх квадратов не использована в PDF. Взята пиктограмма VK из официального комплекта, опубликованная в Wikimedia с указанием источника https://dzen.ru/about/download; SVG сохранён в icons/dzen.svg, исходная чёрно-белая версия сохранена. https://commons.wikimedia.org/wiki/File:Zen_logo_icon_2024.svg. Globe/mail — Lucide, TG/Instagram — действующие знаки сайта.
