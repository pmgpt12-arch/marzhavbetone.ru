# Реестр канонических продуктовых файлов — 13 продуктов

Статус: BOOTSTRAP / HOLD. Этот файл — единая точка учёта, **не утверждение о приёмке**. Никакие старые ZIP, releases, временные каталоги и worktree не считаются актуальным источником автоматически.

## Контракт записи
Одна строка на каждый физический файл каждого из 13 продуктов. Поля: `product_id, relative_path, version, sha256, source_commit, source_pr, owner_issue, content_gate, formula_gate, office2016_gate, pdf_gate, G1_G8, evidence_uri, updated_at`. Для неизвестных данных использовать `UNVERIFIED`, не угадывать. Только `PASS` с доказательствами.

## Правила
1. Актуальный кандидат выбирается только по этому реестру и точному SHA-256; нельзя брать первый найденный файл из архива или worktree.
2. Исполнитель работает в своём изолированном worktree, фиксирует commit/PR и SHA-256. После независимой проверки координатор **явно** меняет указатель канонической версии в реестре. Никакой автоматической синхронизации всех копий и перезаписи чужих изменений.
3. Перед Office QA сверить SHA файла, реально помещённого в пакет, с реестром. Несовпадение — `BLOCKED_VERSION_MISMATCH`; не запускать тест.
4. Результат Office привязывать к точному SHA. Старый PASS не переносить на новую версию.
5. Для DOCX обязателен содержательный gate по запрещённым формулировкам и их смысловым аналогам; для XLSX — проверки расчётов/валидаций, сохранения, печати. Полная приёмка G1–G8 отдельно.
6. Всякое исправление создаёт новый SHA и требует повторных затронутых проверок. Старые файлы остаются историческими, не становятся кандидатами по умолчанию.
7. Не изменять цены, SKU, оплату, VPN, production. Не запускать повторно существующие задачи.

## Инициализация
13 продуктов и полный файловый состав необходимо загрузить из утверждённого реестра #578 и действующих выпусков; до подтверждения каждой строки статус `UNVERIFIED`. Пустые или непроверенные поля не означают PASS. Заполнять только из фактически считанных файлов и SHA-256, с указанием источника. Это предотвращает ложную канонизацию архивной версии.
