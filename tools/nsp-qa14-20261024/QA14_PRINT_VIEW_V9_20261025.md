## Диагностика повторяемых ошибок

1. Исходный реестр имеет фиксированную область печати A1:J107, хотя содержит до 100 незаполненных строк. Печать — пять страниц, две почти пустые.
2. Масштабирование/высота строк v1–v6 не решают проблему без потери читаемости или доступа к данным. **Не повторять масштабирование без нового основания.**
3. Динамическая `_xlnm.Print_Area` через `OFFSET/LOOKUP` в v7: Excel 2016 распознал имя, но при экспорте всей книги выдал пять исходных страниц.
4. v8 с отдельным листом не открылся (COM `0x800A03EC`). Установлена конкретная ошибка порядока OOXML-элементов: `mergeCells` перед `autoFilter`. В v8b порядок исправлен — Excel 2016 открывает, сохраняет и экспортирует. Это ошибка сборщика тестового файла, **не дефект Excel 2016**.
5. v8b: формулы на новом листе «Печать» правильно повторяют данные «Реестр». Фильтр скрывает пустые строки, но **не обновляет видимость автоматически после изменения входных данных**. Печатный итог меняется, сама новая строка остаётся скрытой до повторного применения фильтра.
6. v9 дополнительно содержит инструкцию прямо на печатном листе: после ввода данных на листе «Реестр» открыть «Печать», выбрать «Данные → Применить повторно», печатать только активный лист.

- Конечный v9, точный SHA выше: открытие, сохранение, экспорт — **PASS**, XML receipt SHA-256 `02e179c6308ffaf277e1960981931c1933703fbe24368415696ab25091e79b45`.
- v8b контрольная модель: нативное открытие/экспорт — **PASS**, XML receipt `f955e167238f2476668896120432f88647c240bb57f9d8d6885c76e6bc4dbcdb`.
- Заполненная фикстура: 2 × 250 × 1.15 → 575 ₽, исходная сумма 500 ₽ — **PASS**, XML receipt `beafc7d6442af1f8d568cbdfb1aa0f375a561754dda385637f129744d7512c62`. **Печатная строка без обновления фильтра не отобразилась**, это подтверждённый блокер.
- Контролируемое испытание состояния после раскрытия строки печатного представления (в QA-копии изменён только `hidden` для строки 4): суммы и видимость — **PASS**, XML receipt `2749d87da645dc145499cd1f2bfd2e2a9a4d4ec2892190e53016844dbba89f8a`. Это **моделирование** результата после повторного применения фильтра, а не доказательство самого действия через UI.
- Неполная вторая позиция: Excel 2016 дал F5/I5 «НЕ ЗАВЕРШЕНО», A104 «Предварительно; неполных: 1», сумма заполненной строки осталась 575 ₽ — **PASS**, XML receipt `c86c448032e94a60e9793c0389042ae3e13c8d39a311c03f6248cd1643349414`. Фикстура использовала модель отображения неполной строки.
- Пустой печатный лист (v9), заполненная строка (post-filter state) и неполная строка (post-filter state) визуально читаемы. При печати **всей** книги native PDF 6 страниц, последняя — компактный лист «Печать». Пользователь должен выбирать в диалоге **печать активного листа**, не всей книги.
