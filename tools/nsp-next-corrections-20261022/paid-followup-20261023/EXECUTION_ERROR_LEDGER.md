# Исполнение и исправленные ошибки

- Новый каталог не содержал frozen-inputs: preflight остановил контроллер до отправки. Создан только рабочий каталог; повторно отправлено первое незапущенное задание, id не перезаписывался.
- На сервере отсутствует PyMuPDF, включая render-venv. Вместо установки использованы уже доступные pdfinfo/pdftotext/Poppler. Зависимость убрана до отправки задания.
- ZipFile.writestr меняет поля переданного ZipInfo. При повторном чтении исходного открытого объекта это дало Bad magic number, хотя файлы на диске не повредились. Используется deepcopy(ZipInfo), CRC и сравнение нового архива с исходными байтами; оригиналы не перезаписываются.
- Предыдущий сборщик предполагал наличие PDF до проверки статуса Office. Это скрыло первичную COM-ошибку/таймаут вторичной ошибкой FileNotFound. Исходные XML сохранены. Новый retry_office_after_owner.py сначала сохраняет статус/ошибку и частичные квитанции, обрабатывает PDF только после PASS.
- P5/29: v2 отклонена из-за мелкого текста; v3 — из-за фрагментов объединённых пояснений в соседних группах. В v4 печатаются явные группы таблицы, повторяются идентификаторы, инструкции остаются в книге. Нативная и полная визуальная приёмка не присвоена.
- P11/53: после перестановки уточнены две инструкции, чтобы не ссылаться на письмо «ниже». Нативно принята только v3; промежуточные SHA и квитанции сохранены.
- Ошибка Excel 0x80080005 возникла при создании COM-приложения до открытия любой книги; Word получил TIMEOUT на первом 54. Новые задания автоматически не повторялись, процессы пользователя и системные настройки не менялись.

Продолжение после подтверждения обычного запуска Office владельцем: в исходном рабочем каталоге scripts/retry_office_after_owner.py native, затем после завершения и сверки — word. Оба задания уже заморожены с новыми id. Не подменять отсутствие квитанции PASS старой версией или рендером LibreOffice.

Исходная XML-квитанция COM содержит конечный пробел внутри текста ошибки Windows. Байты и SHA сохранены; whitespace-check исключает только эту одну исходную квитанцию, все остальные staged-файлы проверяются.
