# Ошибки и правила проверки

1. Исходная модель складывала остаток аванса, денежные остатки, расходы и непринятые работы. Первопричина — не определён измеряемый показатель. Правило: складывать только совместимые и непересекающиеся суммы; разные показатели показывать отдельно. Gate: аванс без удержаний даёт 0 удержанных денег; непринятые работы с удержанием не превращаются в удвоенную сумму. Двенадцать сценариев и 60 проверок Artifact Tool пройдены.

2. Наследованный Title содержал синюю границу в paragraph style, а не в самом абзаце. Удалена граница стиля, проверен XML Title и все 12 страниц повторного render_docx.py. Первая редакция сохранена как отклонённая по оформлению.

3. GitHub Fetch отклонил бинарный ZIP как не-UTF-8. Перенос исходных файлов выполнен через DC с побайтовой сверкой SHA; публичный сайт не использовался как источник новой редакции.

4. Команда libreoffice отсутствовала в PATH. Использован установленный runtime-wrapper soffice, который применяет штатный renderer. Новые пакеты и приложения не устанавливались. Печать XLSX проверена в PDF на обеих страницах.

5. Второй движок: десять сценариев дали 50 совпавших значений. Логическое TRUE оказалось числом 1 в итоговом показателе, несмотря на входной XML t=b; ожидаемое значение не изменялось. Последний случай с отрицательной датой не получил экспортированный XLSX до лимита 120 секунд. Причина этапа экспорта не установлена. Правило: проверять типы тестовых входов и различать расчётный дефект, несовместимость движков и сбой экспорта. Gate остаётся закрытым до независимой проверки в Excel, а не заменяется PASS по кешу. Исходники и результаты этих опытов сохранены. Автоматического повторного запуска после таймаута не было.

6. Сигнал ONLINE и свежие GET подтверждают связь с агентом; они не доказывают создание COM-приложения. После последнего отказа контрольного Word/Excel новый продуктовый пакет в очередь не отправлялся. Ожидается новое наблюдение восстановления приложений или диагностика их процессов.

7. Gate путей Git остановился из-за кавычек и octal-экранирования кириллицы в обычном --name-only. Изменён машинный контракт: --name-only -z и разделение по NUL. Файлы не переименованы, scope не расширен; повторный gate проверяет реальные пути. До этой остановки commit/push не выполнялись.
