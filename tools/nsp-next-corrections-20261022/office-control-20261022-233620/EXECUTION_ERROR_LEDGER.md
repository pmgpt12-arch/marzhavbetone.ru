# Исправление журналирования

Whitespace gate остановил фиксацию из-за конечного пробела в собственной строке журнала Word: logger всегда добавлял пустой ERROR, хотя подробной ошибки не было. Изменён узкий logger: ERROR выводится только с непустым текстом. Syntax gate пройден. Офисные задания после этого не повторялись.

Исходный controller.log.txt оставлен побайтно; whitespace gate исключает этот raw log и два исходных XML. Остальной staged-текст проверяется. SHA всех исходных квитанций и источников сверяются отдельно.
