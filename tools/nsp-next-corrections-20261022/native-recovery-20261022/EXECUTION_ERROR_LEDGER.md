# Ошибки исполнения и закреплённые правила

| Воспроизведение / причина | Исправление | Проверка |
|---|---|---|
| Fast-forward sparse checkout удалил вручную материализованные пути, от которых зависел запущенный контроллер; остановка после job10 до job11 | Предварительно проверить ВСЕ файлы/SHAs, затем заморозить полный каталог ввода вне изменяемого checkout | FROZEN_PREFLIGHT.json; job11 и следующие задания получили отдельные квитанции. Не делать checkout/ref mutation при зависимости запущенной работы от этих путей |
| Широкий git archive потребовал promisor-fetch сотен отсутствующих blobs; таймаут оставил дочернюю группу | Прекращена только собственная группа процесса по подтверждённому cwd/PGID; широкий архив заменён чтением малых точных манифестов и проверкой локальных байтов | PRESERVATION_GATE PASS. Бounded Popen(start_new_session=True), при timeout завершать собственную process group; не увеличивать лимит без анализа |
| Ожидали отказ на строку "2"/"3", но COM записал число | Исправлена гипотеза теста, формулы не менялись; добавлены "два"/"три" | Два новых job с уникальными id, 26 checks PASS; исходные FAIL сохранены |
| XML patch: lxml Attrib.update не принимает kwargs; definedNames присутствовал пустым | Проверена структура исходного XML, исправлена только операция/условие | Побайтная неизменность всех остальных частей; нативные print/reopen PASS |
| Контентный patch предположил текст вместо точного исходного ("надежде"/"в надежде", "работы"/"в работу") | Assert остановил запись; считан точный текст, изменён только словарь совпадений | Повторный patch с exact-count gate; 4 новых SHA, Word PASS, все 9 страниц просмотрены |
| После смены заголовка список запретов потерял отрицательную форму; поддержка стала единственным абзацем страницы | Явные корректные действия в списке, условная печать, перенос поясняющего раздела целиком | Финальное задание nsp-free-content-v2-20261022, 4 PASS; 9/9 страниц визуально просмотрены |

Не подменять содержательную, визуальную, нативную, упаковочную и публичную приёмку одним статусом PASS. Промежуточные/отклонённые версии и квитанции сохранять отдельно от финального выбора.
