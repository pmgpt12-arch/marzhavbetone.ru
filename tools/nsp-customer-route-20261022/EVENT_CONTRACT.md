# События бесплатного материала

| Событие | Условие | Дедупликация |
|---|---|---|
| lead_submit | Валидная форма, согласие, начало запроса | Один запрос в полёте |
| lead_ready | Успешный ответ с допустимой ссылкой /downloads/ | Один раз на успешный ответ |
| download_click | Клик по полученной ссылке | Один раз на созданную ссылку |
| download_served | Только подтверждённая сервером выдача байтов | Не реализовано и не заявляется |

Контекст: material, source, first/last source/medium/campaign/content. Контактные поля в параметры целей не передаются. Прежняя клиентская checklist_download больше не вызывается при показе ссылки. Существующее серверное magnet_delivered остаётся событием готовности ссылки и не подтверждает скачивание. Изменение lead.php, настройка целей Метрики и проверка боевого поступления событий в этот выпуск не входят.

Продолжение 23.10.2026: цели lead_submit, lead_ready и download_click
зарегистрированы в реальном счётчике; повторное чтение подтвердило их наличие
(followup/METRIKA_ACCEPTANCE.json). Историческое ограничение настройки целей
выше описывает прежний этап. Реальное поступление этих событий после выпуска
и download_served всё ещё не подтверждены. Новая PDF-форма прошла нативный
локальный PHP; два опубликованных файла действительно получены по HTTP.

add_to_cart считается при фактическом добавлении SKU; purchase и ecommerce
на странице статуса относятся к одному order_id и не складываются как две
продажи. Проверка повторного открытия прошла при доступном localStorage;
между разными браузерами такая отметка не обеспечивает дедупликацию.
