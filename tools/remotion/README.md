# Remotion — текстовые сцены роликов

Кодом рисуются те сцены, где нужна анимация текста: крючок, список
маркеров, счётчик денег, финальный призыв. Внешние картинки не нужны,
вся графика — градиенты и SVG.

Это дополнение к `tools/build_reel.py`, а не замена. Разделение простое:

| Что нужно | Чем делать |
|---|---|
| Текст поверх отснятого или сгенерированного видео | `build_reel.py` |
| Анимированный текст, списки, счётчики как отдельные сцены | Remotion |

## Установка

```bash
cd tools/remotion
npm install
npx remotion browser ensure
```

Второй шаг обязателен: Remotion запускает старый headless-режим, которого
в современном Chromium уже нет, и скачивает себе отдельный
`chrome-headless-shell` (около 88 МБ).

## Рендер

```bash
npx remotion render src/index.ts HookScene out/hook.mp4 \
  --props='{"hookText":"Аванс 5 миллионов — это не ваши деньги","highlightWords":["деньги"],"subtitle":"Разбор в профиле"}'
```

Композиции: `HookScene`, `MarkerListScene`, `MoneyCounterScene`, `CTAScene`.
Схемы props описаны на zod прямо в файлах сцен — оттуда же берутся значения
по умолчанию, если параметр не передан.

**`highlightWords` подсвечивает отдельные слова.** Передать словосочетание
нельзя: `["не ваши"]` не найдёт совпадения и подсветки не будет.

## Что изменено против исходного шаблона

- **Палитра — наша.** Было янтарное на почти чёрном (`#e8a33d` на
  `#0d0f12`), стало оранжевое на графите (`#ff5a00` на `#242629`) — те же
  значения, что в `styles.css` сайта. Иначе ролики выглядели бы другим
  проектом.
- **Субтитры подняты.** Полоса стояла в 120 px от низа, то есть под
  подписью и кнопками Instagram. Поднята до 480 px — эта граница уже
  используется в `build_reel.py`.
- **`zod` закреплён на 3.22.3.** С `^3.22.4` установка падает:
  `@remotion/zod-types` требует ровно эту версию.
- **Concurrency не задан.** В шаблоне стояла четвёрка, а раннер GitHub даёт
  два ядра — рендер падал с «Maximum for --concurrency is 2». Теперь
  Remotion берёт столько потоков, сколько есть на машине.

## Чего в этих сценах не делаем

Эмодзи. В примерах исходного шаблона пункты списка идут с иконками
📈 🔁 🗓 — на сайте и в остальных материалах эмодзи не используются нигде,
и в роликах они будут выглядеть чужеродно.
