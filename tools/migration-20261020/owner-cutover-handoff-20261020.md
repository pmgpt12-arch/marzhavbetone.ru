## Действие владельца №1 — доступ к ЮKassa (без изменения работающего магазина)

1. Войти в личный кабинет ЮKassa **того магазина, который принимает оплаты на marzhavbetone.ru**.
2. Открыть настройки интеграции/HTTP-уведомлений и посмотреть действующий URL для `payment.succeeded` (при наличии также `payment.waiting_for_capture` и других событий).
3. Проверить, что в разделе API-ключей есть действующий **секретный ключ для этого же shopId**. Не присылать секретный ключ, пароли, токены или полный `config.php` в чат и не добавлять их в GitHub.
4. Прислать **скриншот списка HTTP-уведомлений с URL и событиями**, скрыв секреты, и сообщить, разрешено ли нам использовать существующую учётную запись ЮKassa для адресной проверки API. **Не переключать URL на новый домен самостоятельно**: до принятия нового обработчика старый магазин должен продолжать получать POST-уведомления.
5. Если кабинет указывает на необходимость нового ключа или прав, выполнить это только после отдельного согласования плана безопасной замены ключа на хостинге. Проверить сначала read-only `GET /v3/webhooks`, затем реальный платёж, только потом переключение webhook.
