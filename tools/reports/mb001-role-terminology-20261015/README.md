## Решение владельца и правило

Только когда слово «строитель» обозначает сторону, выполняющую работы по договору, использовать **«Исполнитель»**. «Заказчик», «Застройщик», «Генподрядчик», «Субподрядчик» и лицо, фактически выполнившее скрытые работы, не подменяются термином «Исполнитель» без определения их функции в конкретном документе.

Сохранять «строительство», «строительный подряд», «строительный контроль», «строительная площадка», «строительный номер», «лицо, осуществляющее строительство», другие легальные названия деятельности, реквизитов и нормативные определения. При спорном случае — REVIEW_REQUIRED, не автоматическая замена.
