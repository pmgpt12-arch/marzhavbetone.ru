# P3 №09 — точная ссылка на лист реестра

Слой поверх Draft PR #647, исходная ревизия `20eff3aa0cde8cc42b43c5625b6b76ab8c7fabc0`. Все изменения только в изолированном кандидате.

**Причина:** DOCX №09 ссылался на «№02, лист „Реестр“», но актуальный XLSX №02 содержит лист «Реестр приложений».

**Исправление:** единственная строка в `word/document.xml` заменена на «Проверка в комплекте: №02, лист „Реестр приложений“». Фактическая пунктуация с ёлочками сохранена, весь прочий XML и ZIP-состав побайтно неизменны.

**Источник:** SHA256 `465935a45415804811ec167509520d414ffe5a0f19d4b37fea2465df24dafbcf`. **Кандидат:** SHA256 `d107fe9cf43acb7aec2b680736856637a22b422bd55698c237cb721e1dcffafa`.

**Проверено:** `verify_doc09.py` PASS; LibreOffice A4 3/3 страницы осмотрены; нативный Word (ноутбук 192.168.1.140) открыл актуальный SHA, экспортировал PDF из 3 страниц A4, отчёт PASS, PDF SHA256 `8670cd70dc461464226ded737ca3c42dd8b905762f16e290c4d82bf60b7721d2`. Визуально проверены все 3 страницы PDF Word, наложений и обрезаний не обнаружено. Полные SHA-паспорта в `manifest.json`.

**Ограничение:** это одна принятая техническая/визуальная дельта, не принятие всей P3. До G1–G8 необходима интеграция ровно одного комплекта из 11 файлов (документ №09 из этого кандидата и XLSX №06 из PR #647), независимый покупательский gate, формальная номинация и разрешение владельца на выпуск. Merge/production/цены/SKU/оплата/VPN не меняются.
