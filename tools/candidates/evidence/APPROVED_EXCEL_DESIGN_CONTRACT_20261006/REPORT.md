## Проверки и границы

Шесть листов и 2877 формул: «Взаиморасчёты» 2012, «Долг по актам» 337, «Акт сверки» 216, «Реестр передачи» 301, «Реестр приложений» 1, «Сводка» 10. Native print area явно задан только у «Акт сверки»: A1:J51. Отсутствие print area на остальных листах сохранено как факт, а не исправлено.

Девять фактических проверок прошли: неизменённый эталон, разрешимость native style IDs, обнаружение потери формулы, validation, смены защиты листа, защиты ячейки, status formula, print area и number format поля ввода. Негативные изменения делались только в заново прочитанных in-memory копиях. Исходный SHA после проверки совпал. ZIP CRC прошёл; дублирующих имён ZIP нет; модельных/API вызовов при извлечении ноль.

Снимок сохранения семантики находится в `preservation-snapshot.json.gz`, native ZIP-part SHA в `zip-parts.json`; `extract_contract.py` воспроизводит read-only извлечение из локального canonical reference. Он служит доказательством этой единицы, не новым factory framework. Существующий `tools/approved_s1_excel.py` прочитан: его семантические проверки, raw/native validation и сохранение исходных ZIP bytes полезны; `write_approved_layout` предназначен для точного одноимённого шаблона и не переносит оформление между разными продуктами.

Никакой целевой продукт не изменён. Native Excel/Calc rendering, пересчёт, юридическая приёмка и Sale Ready здесь не выполнялись. Отрицательные проверки охватывают семь заявленных классов изменений, а не все возможные потери OOXML. При переносе все неподдерживаемые extension/ZIP части должны сохраняться отдельно raw comparison; openpyxl load/save сам по себе не подтверждает native preservation.

## Предотвращение ошибки происхождения metadata

Завершающий gate выявил, что openpyxl материализует границы объединённых ячеек и регистрирует 3 synthetic style IDs (411–413), отсутствующих в исходном cellXfs. Класс: LOSS_OF_NATIVE_METADATA_ORIGIN. Правило: карта coordinate/style извлекается только из raw worksheet c/@s, не из in-memory style_id merged cells. Реализованный gate проверяет каждый native ID относительно actual cellXfs (411 записей). После исправления все ссылки разрешаются. Первая версия контракта не использовалась для изменения продукта.
