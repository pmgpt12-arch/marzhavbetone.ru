## 3. Паспорт P2 → система «Допработы»

### 3.1. Проблема, ЦА, исходные условия

- **ЦА.** Субподрядчик или подрядчик (директор, ПТО, начальник участка),
  которому на объекте устно поручают объём сверх договорной ведомости.
- **Проблема.** Оплачивают документ, а не бетон. Без предупреждения заказчика
  подрядчик может потерять право требовать оплаты допработ — даже если акт потом
  подписали. Опоры к сверке: п. 3–4 ст. 743 ГК РФ, п. 10 Информационного письма
  Президиума ВАС РФ от 24.01.2000 № 51. Позиция по ст. 743 изложена в статье
  сайта `articles/dopraboty-bez-soglasheniya.html`; первоисточник в этом заходе
  не открывался — NOT VERIFIED.
- **Исходные условия.** Три стадии, и на каждой свой набор документов:
  **А** — до начала, **Б** — во время выполнения, **В** — уже выполнено без согласования.

### 3.2. Результат для покупателя

На каждый допобъём есть письменная классификация («допработа / изменение
заказчиком / новые работы / входит в твёрдую цену»), доказанное предупреждение,
подтверждённые полномочия инициатора, цена с методом расчёта, влияние на срок
и подписанное основание. Объём включён в КС-2/акт и передан в S1. Если
основания нет — собран пакет с хронологией и описью для специалиста, а сумма
под риском посчитана.

### 3.3. Маршрут с развилками (целевой)

```
Q0 Объём есть в договорной ведомости / смете?
 ├─ да → это не допработа → S1 (обычная сдача)
 └─ нет → K Классификация
     ├─ K1 необходима для результата, не учтена в техдокументации (ст. 743)  → основной маршрут
     ├─ K2 заказчик меняет техдокументацию (ст. 744)                         → основной маршрут, основание — распоряжение заказчика
     ├─ K3 новые работы вне предмета договора                                → отдельное соглашение/договор; без него — граница специалиста
     └─ K4 входит в твёрдую цену или риск подрядчика (п. 4, 6 ст. 709)       → STOP: не допработа; пересмотр цены — граница специалиста
 Сквозные развилки до любой стадии:
   P  полномочия инициатора: есть / нет / последующее одобрение (ст. 182, 183)
   Z  режим закупки 44-ФЗ / 223-ФЗ → граница: изменение существенных условий ограничено законом
   U  нужны немедленные действия в интересах заказчика → фиксировать отдельно (исключение п. 4 ст. 743)
   H  объём закроется конструкциями → освидетельствовать до закрытия (форма — «ИД и сдача»)
 Стадия:
   А до начала:  уведомление → ответ: согласие / отказ / молчание в срок
                 согласие → допсоглашение (объём, цена, срок) → выполнение → акт допобъёма → КС-2 → S1
                 отказ    → не выполнять; если работа необходима для результата — развилка ст. 743 / ст. 716
                 молчание → приостановка по п. 3 ст. 743 в срок из договора или закона (без числа в тексте)
   Б во время:   стоп-письмо (только меры по предотвращению ущерба), фиксация состояния, уведомление задним
                 числом НЕ составлять — датой дня; дальше как А
   В выполнено:  хронология → разложение доказательств по пяти вопросам → расчёт по методу →
                 проверка полномочий и одобрения → письмо с проектом допсоглашения и акта →
```

## 5. Паспорт P4 → система «ИД и сдача»

### 5.1. Проблема, ЦА, исходные условия

- **ЦА.** ПТО и руководитель субподрядчика. Отдельно — субподрядчик без своего
  ПТО, у которого ИД ведёт прораб.
- **Проблема.** ИД — условие приёмки, а часто и оплаты по договору. Скрытые
  работы без акта до закрытия потом подтверждаются только вскрытием или
  экспертизой. Возвращают обычно связку документов, а не работу
  (`00-free-id-do-peredachi/03`, «Девять причин»).
- **Исходные условия.** Четыре стадии: ведение по ходу работ → сборка к
  периоду → передача → замечания и сдача.

### 5.2. Результат

По каждой позиции КС-2 за период есть полная цепочка ИД: поставка → входной
контроль → запись журнала → АОСР до закрытия → исполнительная схема → реестр.
Комплект передан со следом. Замечания к ИД закрыты по реестру или выделены
в бесспорную и спорную части. Акт приёмки ИД подписан. Дальше — S1, проверка G.
