## Проверка опубликованных байтов

Зависимости: Python 3, lxml, python-docx, Poppler (`pdfinfo`, `pdftoppm`); LibreOffice нужен только для нового DOCX-рендера.
Из каталога этой задачи: сначала `python3 render_saved_previews.py`, затем `python3 verify_final.py`. Первый скрипт создаёт изображения из сохранённых QA PDF, не повторяет нативные Office-задания. Сверять PDF/DOCX SHA и просматривать страницы независимо. Наличие авторского JSON не заменяет собственного вердикта проверяющего.

`build_candidate.py` воспроизводит предметную дельту из `inputs`; два layout-скрипта фиксируют последующую адресную коррекцию №01. Побайтная детерминированность новой пересборки DOCX не заявляется: служебные ZIP-времена могут отличаться. Frozen SHA относятся к сохранённым и проверенным документам. При изменении артефакта нужен новый SHA и только затронутые проверки. Не перезапускать весь набор прежних продуктовых задач.
