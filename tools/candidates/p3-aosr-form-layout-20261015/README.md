## Замечание и правило
Владелец выявил недопустимое обозначение стороны «Строитель». Во всех пяти АОСР сторона, выполняющая работы по договору, обозначается **«Исполнитель»**. Для точности при первом упоминании сохраняется нормативное описание «лицо, осуществляющее строительство, реконструкцию, капитальный ремонт». «Строительный контроль», «строительство», «строительный адрес» не являются именами стороны и не заменяются. Фактическое лицо, выполнившее скрытые работы, может быть другим участником; его поле отдельно переименовано в «Представитель исполнителя работ», чтобы не смешивать роли.
