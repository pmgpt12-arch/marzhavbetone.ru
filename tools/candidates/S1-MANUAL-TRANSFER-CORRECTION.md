## Тесты (`tools/test_s1_candidate.py`)

Помощник `заполнить_395` получил параметры `итог04` и `вне04`.
По умолчанию в B5 пишется сумма сверочных остатков, поэтому прежние сценарии вводят правильную бесспорную часть и сохраняют свои итоги.

Новые тесты:

- `test_r1_книга_расчёта_сверяет_итог_с_файлом_04` (статика): поле B5 со ссылкой на M12, формула сверки, пункт в 09.

  - J/M + 870 000 → ГОТОВ, сверка «ок», **45 678,91** = эталону, долг **870 000**;
  - H/L + 870 000 → **ЗАБЛОКИРОВАН**, «сверка с файлом 04 не сходится»;
  - H/L без B5 → ЗАБЛОКИРОВАН (раньше было ГОТОВ, 51 019,17);
  - J/M без B5 → ЗАБЛОКИРОВАН, «не внесена бесспорная часть»;
  - H/L + 870 000 + B6 = −130 000 → ЗАБЛОКИРОВАН, «не меньше нуля»;
  - только акт A + 870 000 + B6 = 220 000 → ГОТОВ, проценты = эталону по A, долг 650 000;
  - только акт A + 870 000 без B6 → ЗАБЛОКИРОВАН.
