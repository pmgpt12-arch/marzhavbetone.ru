## 4. Предложенные системы

### 4.1 «До подписи»: P7 / P8 (первая половина) / P13

Покупательская задача одна — подписывать ли и на каких условиях. Документы

**Автоматически не объединять.** Причины: покупатель приходит с одним
документом на руках; P7 по качеству не готов (P7-Q1); вторая половина P8 —

проверки». Единственная общая точка, которой не хватает, — свод трёх

договору. Это требование к G2 P7. Системного SKU не предлагается, пока P7 не
