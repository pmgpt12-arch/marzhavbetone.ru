## 3. Тест `tools/test_p5_claims.py`

Проверяется START-HERE и страница P5 целиком: видимый текст, meta и JSON-LD.

- Нет долей без источника: `N %`, «половина», «треть», «четверть», «большинство», «в N случаях из M».
- Нет обещаний, для которых в составе нет опоры. Список с причиной у каждой фразы.
- Инструкция совпадает с архивом (`check_packages.delivered`):
  - §4 = выдаваемые файлы;
  - §2 называет ровно один файл;
  - §3 ссылается только на существующие номера и упоминает каждый рабочий файл;
  - пропуск в нумерации объяснён;
  - если первым открывается не первый по номеру файл, нумерация не называется порядком применения;
  - один PDF не описывается множественным числом.
- Сторож: детекторы проверены на положительных и отрицательных примерах.
