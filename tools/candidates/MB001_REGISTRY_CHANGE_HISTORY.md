# MB001: история изменений и возобновление без повторов

Контрольный реестр: Issue #600. Родитель #291. Записи находятся в существующем products-storage/ARTIFACT-REGISTRY.json, поле change_history; это не новая очередь и не реестр релиза.

Каждая запись: точные версии до/после; SHA-256, Git blob, байты, исходный путь и сохранённая копия; OOXML-параметры и адресный delta; сырые отчёты, PDF и скрипты; результат каждого gate с ограниченным scope; runtime/contract/dependency fingerprints; открытые дефекты; следующий атомарный шаг. Неизвестное отмечено null с причиной.

Перед повторным Office/model заданием: `python3 tools/build_artifact_registry.py --check --reuse-request <request.json>`. JSON запроса содержит record_id, gate_id, actual_input_path, contract_sha256, environment_fingerprint, dependency_fingerprint. Значения текущего контракта/среды/зависимостей поступают из фактического preflight, не копируются автоматически из старой записи. Команда не запускает исполнителей.

REUSE_VERIFIED_RESULT: проверка уже выполнена на этих входах; не запускать повторно. BLOCK_KNOWN_FAILURE: сначала исправление причины. WAIT_EXISTING_JOB: читать существующий результат. DELTA_RECHECK_REQUIRED: проверить только затронутые изменения, не повторять весь аудит. RESOLVE_DEPENDENCY/CHECK_REQUIRED: завершить указанное недостающее звено.

История append-only: SHA-цепочка; исправление прежнего вывода оформлять новой записью, не переписывать прошлый результат. Локальные evidence-copy имеют роль доказательств, не становятся canonical автоматически. Исполнители, ещё не вызывающие этот preflight, не считаются автоматически подключёнными к защите повторов.
