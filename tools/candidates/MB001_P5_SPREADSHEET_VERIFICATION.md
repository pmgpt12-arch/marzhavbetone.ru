проверяется по коду ошибки ячейки и статическим поиском самоссылки.

## 5. Тест `tools/test_p5_spreadsheets.py`

Проверяет все `*.xlsx` в папке выдачи P5 (или в `--dir` / `P5_BOOKS_DIR`).

- Статический слой (только стандартная библиотека, работает без Calc): формула не накрывает свою
  ячейку; имя листа ≤ 31; итоговые `SUM(E2:E20)` и `SUM(D2:D10)` на месте; сторож детектора.
- Слой Calc: пересчёт и сохранение; нет ячеек-ошибок; имена листов и формулы пережили сохранение;
  итог суммирует введённые значения. Нет Calc/openpyxl — строка «ПРОПУСК» с причиной;
  `P5_REQUIRE_CALC=1` делает её провалом.

| Прогон | Результат |
|---|---|
| книги из `main` (`--dir` с копиями `git show origin/main:…`) | **exit 1**: 3 провала — самоссылка E5, D4; имена 37 и 33; Calc `#VALUE!` ×2, обрезка имён ×2, итог `#VALUE!` вместо 4000,5 ×2 |
| книги из `main` без Calc в PATH | exit 1: 2 провала (статический слой) |
| книги ветки, `P5_REQUIRE_CALC=1` | **exit 0**, 5/5 ок |
| книги ветки без Calc в PATH | exit 0, «ПРОПУСК пересчёт Calc: soffice не найден» |

В реестр CI (`tools/ci_checks.yaml`) тест не внесён — это вне разрешённого списка файлов; в CI
нет ни Calc, ни openpyxl, там работал бы только статический слой.

## 6. Воспроизводимость

openpyxl пишет время сборки в `docProps/core.xml` (`dcterms:created`, `dcterms:modified`) и в даты
записей zip — две сборки различались побайтно. `save_workbook` нормализует оба места к постоянной
`2026-09-28T00:00:00Z` и права записей zip к 0644. Две сборки подряд (с паузой 2 с):

| Файл | sha256, оба прогона |
|---|---|
| `04-raschet-ubytkov.xlsx` | `8385667423bb…` = `8385667423bb…` |
| `05-reestr-uderzhaniy.xlsx` | `1434fecf40e9…` = `1434fecf40e9…` |
| `06-grafik-vozmeshcheniya.xlsx` | `f28f7502a5e8…` = `f28f7502a5e8…` |

`04` из генератора отличается от `04` в `main` только `docProps/core.xml` (даты), остальные 8 частей
побайтно равны; файл оставлен как в `main`.

**Не нормализовано (вне scope):** `.docx` и `.pdf` P5 при каждой сборке различаются (время в
метаданных). Штатный запуск генератора также перезаписывает все `.docx`/`.pdf` комплекта и заново
создаёт снятый из выдачи `09-sravnitelnaya-tablica.docx`. В этом PR они возвращены к `main`,
`09` удалён; в коммит попали только две книги.
