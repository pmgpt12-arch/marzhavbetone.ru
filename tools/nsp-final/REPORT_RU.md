## Причины и предотвращение повторений

**Счётчики и категория P10.** Карта генератора содержала снятые с продажи SKU и относила P10 к банкротству; навигационные числа расходились с карточками. Исправлен существующий `tools/catalog_groups.py`. Счётчики выводятся из фактических карточек, неизвестный платный SKU или отклонение от 13 разрешённых позиций останавливает запись. Добавлен `NSP catalog contract`; он проверяет обе системы счётчиков, состав групп, 10 бесплатных материалов и цены. Проверка намеренно неверного счётчика дала отказ; повторный запуск генератора не изменил страницу.

**Резервное копирование.** Ошибка BACKUP_EXISTS_WITH_DIFFERENT_CONTENT возникала при сравнении нового config с одной исторической копией. Общий helper `tools/nsp_backup_config.sh` создаёт новый файл с UTC-датой, run_id, attempt и уникальным суффиксом; каталог 0700, файл 0600. Копия сверяется с текущим источником, исторический файл не перезаписывается. Локальный регрессионный тест с законной сменой config прошёл. На production созданы и проверены две разные копии в одном run/attempt; исторический файл сохранил SHA. Квитанции — `evidence/backup-receipts.txt`.

В ветке старого аудита дополнительно исправлен `.github/workflows/deploy.yml`: все 47 jobs имеют адресные условия запуска, прежде безусловные jobs требуют workflow_dispatch и явно выбранный migration_action. Заморозка общего legacy deploy сохранена и там. [Коммит исправления 249c1a9](https://github.com/pmgpt12-arch/marzhavbetone.ru/commit/249c1a92cf0bf08dfbbfc375cccc0de216eb86b0). Весь старый workflow не запускался и PR #670 целиком не сливался.

**Публикация.** Перед записью проверяется SHA каждого живого файла. Резервные копии находятся вне webroot; запись атомарна для каждого файла. При ошибке проверки HTTPS выполняется откат только собственных изменений с отказом при конкурирующей правке. Тесты на конкурирующее редактирование и фактический откат прошли на одноразовой фикстуре в Actions до работы с production. Платёжный PHP и мастера контролируются отдельно по отпечаткам.

**Первый снимок.** Попытка 39559738010 остановилась, потому что публичный rss.xml исключён через .gitignore. Исправлено добавление только явного списка разрешённых публичных файлов. Следующий снимок прошёл. Публичных изменений в неуспешной попытке не было.
