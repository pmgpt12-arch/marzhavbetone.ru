## Что НЕ выполнено

**P2 v13 не опубликован.** Историческая блокировка публикационного исполнения инструментом не снята. Блокированные команды не повторялись и через другой канал не запускались. `p2-publish` по-прежнему не реализован; эту папку нельзя обозначать полностью завершённым техническим выпуском. Запрос workflow не изменён, новые production-действия не запускались.

Остаётся техническая реализация и разрешённое исполнение адресного обновления выдачи, затем проверка реально полученного архива. Проверять нужно точное совпадение SHA v13, сохранность старых заказов и архивов, отсутствие изменений цены и других товаров. Старый PHP-сборщик пересоздаёт ZIP из мастеров: одного совпадения списка 13 файлов недостаточно, чтобы гарантировать идентичность ZIP принятому архиву. Повторные callback для старого P2 также нельзя автоматически переводить на новое издание. Эти свойства требуют отдельной проверки существующего механизма, а не нового платёжного обработчика.

Нельзя сливать весь PR #677 ради P2: он содержит другие незавершённые SKU. Подготовка P2 сохраняется в действующей ветке публикации; main, сайт, платёжные обработчики, конфигурация выдачи и покупательский архив не изменены.

## Защита от повторения ошибки

Ошибочный прежний вывод: сохранённый архив и успешный snapshot принимались за почти завершённую публикацию. Правило: отдельно фиксировать **принятие комплекта**, **готовность выпускных материалов**, **реализацию исполнителя**, **фактическую выкладку**, **проверенную выдачу**. Успех одного этапа не заменяет остальные. У этой редакции первые два подтверждены, последние три — нет.
