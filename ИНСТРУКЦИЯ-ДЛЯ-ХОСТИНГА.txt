ШАГ 1. СКЛЕЙКА ЗЕРКАЛ (301-редиректы)
═══════════════════════════════════════════════════════════════════════════════

Все запросы ДОЛЖНЫ редиректиться 301 на https://marzhavbetone.ru

Проверьте сейчас:
  • http://marzhavbetone.ru        → ДОЛЖЕН редиректить 301 на https://
  • http://www.marzhavbetone.ru    → ДОЛЖЕН редиректить 301 на https://
  • https://www.marzhavbetone.ru   → ДОЛЖЕН редиректить 301 на https:// (без www)
  • https://marzhavbetone.ru       → ЕДИНСТВЕННАЯ рабочая версия (200 OK)

Если у вас nginx:
  → скопируйте содержимое файла nginx-marzhavbetone.conf
  → вставьте в блок server { } вашего виртуального хоста
  → перезапустите nginx:  sudo systemctl restart nginx

Если у вас Apache:
  → файл .htaccess уже в архиве, залейте его в корень сайта
  → убедитесь, что в главном конфиге Apache разрешён AllowOverride All
  → перезапустите Apache:  sudo systemctl restart apache2

ШАГ 2. HSTS (Strict-Transport-Security)
═══════════════════════════════════════════════════════════════════════════════

Добавьте заголовок ко ВСЕМ HTTPS-ответам:

  Strict-Transport-Security: max-age=63072000; includeSubDomains; preload

Это заставляет браузер ВСЕГДА заходить на сайт по HTTPS,
даже если пользователь набрал http:// вручную.

⚠ ВАЖНО: включайте HSTS ТОЛЬКО после того, как убедитесь,
  что HTTPS работает корректно на ВСЕХ страницах!

ШАГ 3. КЕШИРОВАНИЕ СТАТИКИ (Cache-Control)
═══════════════════════════════════════════════════════════════════════════════

Добавьте заголовки Cache-Control по типам файлов:

  HTML-страницы (.html):
    Cache-Control: public, max-age=3600, must-revalidate
    (1 час — чтобы обновления индекса применялись быстро)

  CSS и JavaScript (.css, .js):
    Cache-Control: public, max-age=604800, immutable
    (1 неделя)

  Изображения, шрифты, иконки (.jpg, .png, .svg, .woff2 и т.д.):
    Cache-Control: public, max-age=2592000, immutable
    (1 месяц)

  PDF, ZIP и документы:
    Cache-Control: public, max-age=604800
    (1 неделя)

В nginx эти правила уже прописаны в nginx-marzhavbetone.conf
в блоках location ~* \.(расширение)$

ШАГ 4. ОПТИМИЗАЦИЯ TTFB (время до первого байта)
═══════════════════════════════════════════════════════════════════════════════

Текущая проблема: TTFB 1.3–2.6 секунд для СТАТИЧЕСКОГО HTML.
Это НЕНОРМАЛЬНО. Должно быть < 0.2 сек.

Проверьте и включите:

  1) sendfile on;          (в nginx) — обязательно!
  2) tcp_nopush on;        (в nginx) — улучшает отправку больших файлов
  3) tcp_nodelay on;       (в nginx) — уменьшает задержки
  4) keepalive_timeout 65; (в nginx) — поддержание соединений

Если TTFB всё ещё высокий — проверьте:
  • Нет ли лишних реверс-прокси между пользователем и nginx?
  • Не работает ли антивирус/файрвол на хостинге с проверкой каждого запроса?
  • Не перегружен ли сервер (CPU/диск)?
  • Не включён ли mod_security / WAF с агрессивными правилами?

ШАГ 5. ПРОВЕРКА ПОСЛЕ ПРИМЕНЕНИЯ
═══════════════════════════════════════════════════════════════════════════════

Проверьте каждый пункт онлайн:

1. Редиректы:
   https://www.redirect-checker.org/
   Введите: http://marzhavbetone.ru
   Ожидаемый результат: 301 → https://marzhavbetone.ru

2. Заголовки сервера:
   https://httpstatus.io/
   Введите: https://marzhavbetone.ru/
   Проверьте наличие:
     • Strict-Transport-Security
     • Cache-Control
     • X-Content-Type-Options

3. HSTS:
   https://hstspreload.org/
   Введите домен, проверьте что HSTS работает.

4. Скорость (TTFB):
   https://pagespeed.web.dev/
   Проверьте показатель TTFB после внесения изменений.
