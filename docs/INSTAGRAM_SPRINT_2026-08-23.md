## Три отклонённые партии и причины

**Партия 1 — ролики 1–3 (V1).** Формат: обложки разборов + панорама +
надписи + озвучка. Замер: 18 планов, все 18 из `assets/`, три обложки
стоят в двух роликах сразу. Отклонены 17.08 как автонарезка материалов
сайта. Разбор — `content/reels/RESET-2026-08-17.md`.

**Партия 2 — ролики 8–10.** Кадры генерировались под сцены, обложек не
было, но сборка осталась «картинка висит пять секунд, поверх фраза».
Отклонены: «презентация, сохранённая в mp4». Плюс призыв «ссылка в
профиле» противоречил принятой воронке через директ.

**Партия 3 — ролик 8, вторая редакция.** Монтаж переделан: новая сцена
`BeatScene` режет один исходник на несколько планов жёсткими резами,
девять визуальных событий за 21 секунду вместо пяти. Призыв переведён в
директ. Отклонена по новому требованию: **основа всё равно неподвижные
изображения**, а панорама по фотографии видеосценой не считается.

Общий вывод, который стоит запомнить: каждая партия чинила названный
дефект и упиралась в следующий, более глубокий. Текущая граница —
источник кадра, а не монтаж и не текст.

## Действующее требование к видеоряду (17.08, VIDEO-FIRST)

- В ролике обязаны быть настоящие движущиеся сцены: люди, техника,
  документы в руках, подпись, проход по объекту.
- **Не меньше 60–70% хронометража** — живое видео; статика, документы и
  графика — не больше 30–40% и только смысловыми вставками.
- Zoom по картинке видеосценой не считается. Псевдовидео «статичный
  человек, камера приближается» — тоже.
- Критерий владельца: «если убрать текст, я вижу настоящий видеоролик, а
  не набор картинок».
- В сториборде у каждой сцены объявлен тип — VIDEO / DOCUMENT / GRAPHIC /
  CTA, а у VIDEO ещё и что именно движется в кадре.

## Призыв к действию

Первичный призыв — **слово в директ**, не «ссылка в профиле». Слово и
материал берутся из готовой карты `data/social/ig-keywords.yaml`; новые
пары не придумываются, потому что выдаёт по слову `ig-webhook.php`.

Для удержания: слово `УДЕРЖАНИЕ` → `materialy/uderzhaniya.html` (четыре
файла). Слово обязано совпадать в пяти местах — финальный кадр, озвучка,
подпись, блок маршрута сценария, карта слов; это проверяет гейт.

До App Review на слово отвечает владелец руками. При нуле подписчиков
выполнимо; возврат к ссылке в профиле из-за этого не делается.

## Что построено в инструментах

- `tools/build_reel_v2.py` — сборка по плану сцен, Remotion + ffmpeg.
- `tools/remotion/` — сцены `HookScene`, `BeatScene`, `PhotoStatementScene`,
  `MarkerListScene`, `MoneyCounterScene`, `CTAScene`.
- `tools/check_reel.py` — гейт: блок маршрута, тип призыва, слово для
  директа, существование целевой страницы, финальный кадр 2–4 с, доля
  обложек, не меньше пяти сцен, окно 15–30 с.
- `tools/test_check_reel.py` — восемь порченых случаев, каждый требует
  отказа поимённо.
- `ig-webhook.php` + `tools/test_ig_webhook.php` — выдача по слову.

Все три проверки стоят в `checks.yml`. До 16.08 проверка сценариев в
гейте не стояла вовсе — только в хуке, который можно не запустить.

## Где остановился заход 23.08 после выдачи ключа

`SCRAPECREATORS_API_KEY` заведён владельцем. Карточек всё равно нет, и
причина не в ключе — до него нечем добраться.

| попытка | результат |
|---|---|
| Кнопка `trends.yml` | 404: кнопку GitHub даёт только прогонам с ветки по умолчанию, зарегистрировано 16, этого среди них нет |
| Вход по толчку в ветку | сработал — прогон 32636274728 создан |
| Размещённый раннер | заданий не берёт: оплата учётной записи |
| Self-hosted | задание с меткой висит `queued` больше девяти минут, исполнителя нет |
| Вызов из сессии | `api.scrapecreators.com` → CONNECT 403, замерено трижды |

Прогон 32636274728 намеренно оставлен в очереди: он выполнится сам, как
только появится раннер. Отдельно запускать ничего не нужно.

Разблокирует любое из двух, и оба — действия владельца:

1. Оплата в разделе Billing & plans, затем кнопка `trends.yml` с
   `runner: ubuntu-latest`.
2. Поднять self-hosted раннер — очередь разберётся сама.

До карточек ролик R-08 остаётся на стадии `research`: критичный раздел
