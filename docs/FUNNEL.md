# Воронка по целям счётчика

Собран `python3 tools/funnel_report.py --write` из снимков
`content/metrics/site-*.yaml`. Каталог `content/` не
деплоится, поэтому числа остаются внутренними, а отчёт —
здесь.

**Ноль и «не измерено» здесь разные вещи.** Метрика по цели,
не объявленной в счётчике, молчит: в выгрузке её нет. Пустое
место читается как «никто не дошёл», а означает «прибор не
подключён».

**Доля от знаменателя меньше 30 не
называется.** При таком трафике один клик двигает её на
проценты, и это шум, а не измерение.

```
Снимок site-2026-08-14.yaml, период 2026-08-07 — 2026-08-13; визитов 34

   ступень                                                 значение  доля от предыдущей
   Пришли на сайт                                                34  —
   Ушли с контента к товару или к бесплатному                     0  измерено не всё: молчат cross_sell_click, calculator_to_product, calculator_diagnostic_click
   Открыли страницу товара                                        0  нет сигнала (знаменатель 0)
   Положили в корзину                                             0  нет сигнала (знаменатель 0)
   Открыли оформление                                             0  нет сигнала (знаменатель 0)
   Оплатили                                             не измерено  —

   Ветка бесплатного материала
   Открыли бесплатный материал                                    0
   Скачали чек-лист                                               0
   Оставили контакт                                               0

   Диагностика и калькулятор
   Начали диагностику                                   не измерено
   Дошли до сценария                                    не измерено
   Считали калькулятором                                не измерено

   После покупки
   Взяли предложение после покупки                      не измерено

Снимок один. Ряда нет, сравнивать не с чем: любое число здесь — точка, а не динамика.
Ступени, по которым прибор молчит, а не показывает ноль:
  · Ушли с контента к товару или к бесплатному — частично: cross_sell_click, calculator_to_product, calculator_diagnostic_click
  · Оплатили (purchase)
Цели заводит сам прогон `metrika.yml --create-goals`; до этого пустое место в выгрузке — свойство счётчика, а не поведение людей.
```
