# Жизненный цикл ролика: постоянные правила контура Instagram

Указание владельца 23.08.2026. Файл постоянный: он существует, чтобы новая
сессия не зависела от памяти чата. Читается после `docs/KNOWLEDGE_INDEX.md`
и до любой правки роликов.

Где проверяется автоматически — названо в скобках. Где проверить нечем —
сказано прямо: субъективное качество картинки остаётся владельцу, и
доказывать его тестом никто не пытается.

## Стадии

Ролик объявляет стадию строкой `**Стадия:**` в шапке сценария. Стадия —
не украшение: с `pre_production` включаются ворота доказательств
(`tools/check_reel_refs.py`).

```
research → reference_selected → concept → script → storyboard →
source_assets → self_qa → owner_pre_production_review →
approved_for_generation → video_generation → render → final_self_qa →
owner_final_review → approved_for_publish → published
```

Два места, где решает владелец, а не сессия:

| ворота | что разрешает | чего НЕ разрешает |
|---|---|---|
| `owner_pre_production_review` | платную съёмку и рендер | публикацию |
| `owner_final_review` | публикацию | ничего сверх неё |

**Молчание — не согласие.** Автоматического утверждения по таймауту нет и
не заводится. Первое утверждение не открывает публикацию: это два разных
решения на разных материалах — сториборд и готовый mp4.

## Что обязано быть до платной генерации

Каждый пункт — отказ, а не пожелание.

1. **Референсы.** Не меньше трёх разобранных чужих роликов с числами, один
   выбран, у выбранного названо, что переносится и что не копируется
   (`tools/check_reel_refs.py`). Карточки собирает
   `tools/trend_provider.py` — источники объявлены в
   `data/social/trend-providers.yaml`. Механику переносим, содержание нет:
   чужой текст, бренд, автор, лицо, сюжет, музыка и видеоматериал остаются
   у автора.
2. **Крючок**, понятный без звука и без контекста в первую секунду.
3. **Сценарий целиком** — озвучка, надписи, подпись. Не пересказ.
4. **Сториборд по секундам** с двенадцатью полями у каждой сцены:
   SCENE ID, TIME, TYPE, VISUAL, ACTION, CAMERA, SOURCE ASSET, ON-SCREEN,
   VOICEOVER, TRANSITION, PURPOSE, RETENTION FUNCTION.
5. **Тип сцены** — только из набора: `REAL VIDEO`, `GENERATED VIDEO`,
   `DOCUMENT`, `STATIC IMAGE`, `KINETIC TYPOGRAPHY`, `COMPOSITE`, `CTA`.
   У видеосцены названо, что именно движется **внутри** кадра.
6. **Доля живого видео** — посчитана и напечатана:

   ```
   TOTAL / REAL VIDEO / GENERATED VIDEO / MOVING TOTAL / STATIC / MOVING %
   ```

7. **Исходники** — владелец видит картинки, а не пути к файлам.
8. **План генерации** по каждой сцене: опорный кадр, модель, ожидаемая
   стоимость, длительность, промпт, запреты, действие персонажа, действие
   среды, движение камеры.
9. **Призыв** — слово в директ из `data/social/ig-keywords.yaml`,
   совпадающее в пяти местах (`tools/check_reel.py`).
10. **Утверждения** — проверены; чего не подтверждено, того в ролике нет.

## Абсолютные ворота: живое видео

Решение владельца 17.08.2026, подтверждено 23.08.2026.

**Не меньше 60% хронометража — настоящее движущееся видео.** Статика,
документы и графика — не больше 40% и только смысловыми вставками.

Не считается видеосценой:

- зум, панорама, кроп и параллакс по неподвижной картинке;
- «статичный человек, камера приближается»;
- обложка разбора с наездом.

Считается: клип, где движется предмет, человек, техника или документ.

Доля ниже 60% — **самоотказ**. Владельцу такой вариант не показывают
вовсе. Проверить это кодом нельзя (тип сцены объявляет автор), поэтому
здесь работает дисциплина, а расчёт печатается в сценарии, чтобы его
можно было проверить глазами за десять секунд.

## Призыв: решение закрыто

С 17.08.2026 первичный призыв — **слово в директ**. Запрещены «ссылка в
профиле», «перейди по ссылке», «скачай в bio». Одновременно «пиши в
директ» и «ссылка в профиле» — тоже запрет: два первых шага это ни одного.

Слово и материал берутся из `data/social/ig-keywords.yaml`. Новые пары
слово-материал не придумываются: выдаёт по слову `ig-webhook.php`, и
слова, которого там нет, выдать нечем.

**Комментарий и директ не путаются.** Автоматический ответ в личные
сообщения требует прав `instagram_manage_comments` и
`instagram_manage_messages` — они ждут App Review. До них на слово
отвечает владелец руками. Обещать в ролике то, чего механизм не делает,
нельзя; возвращать ссылку в профиле из-за этого — тоже нельзя.

## Утверждение привязано к версии

Утверждается не «ролик», а конкретная его версия. Пакет несёт REEL ID,
версию и хеши: сценария, сториборда, манифеста исходников. Изменилось
любое из них — прежнее утверждение недействительно, нужен новый заход.

Механизм для этого уже есть и второй не заводится: очередь решений
владельца в `ai-business-os` (`app/review.py`, `/api/review/{id}/decision`)
пересчитывает хеш перед применением решения и отвечает 409 на кнопку от
другой версии. Транспорт — управляющий бот того же репозитория
(`app/telegram_api.py`): фото, документы и кнопки в нём уже есть.

Второго Телеграм-бота, второй базы, второго конвейера и второй панели не
создаётся.

## Чего в проекте нет

**Автоматизированного контура Virale не существует.** Проверено поиском по
`docs/`, `tools/`, `data/`, `.github/` — ноль совпадений; у самого продукта
не найдено ни API, ни MCP, ни выгрузки. Утверждать обратное нельзя.
Скрейпинг чужого интерфейса браузером не заводится, пока есть источники с
объявленным API (`data/social/trend-providers.yaml`).

## Самопроверка перед показом владельцу

Вердикт по каждому разделу выводится до отправки:

```
CURRENT STATE · REFERENCE EVIDENCE · HOOK · SCRIPT · STORYBOARD ·
VIDEO-FIRST · MOTION · ASSETS · RHYTHM · SCREEN TEXT · CTA/DM ·
FREEBIE · CLAIMS · AUDIO PLAN · INSTAGRAM NATIVE
```

Критичные — `REFERENCE EVIDENCE`, `HOOK`, `STORYBOARD`, `VIDEO-FIRST`,
`CTA/DM`. Любой из них FAIL — стоп.

**Показывать владельцу работу с известным себе дефектом запрещено.**
Просить его найти этот дефект — тем более. Раздел, который проверить
нечем (звук до синтеза, нативность до готового файла), помечается «не
проверялось», а не PASS.

## Проверки контура

```bash
python3 tools/check_reel.py        # маршрут, призыв, слово в пяти местах, окно
python3 tools/test_check_reel.py   # восемь порченых случаев
python3 tools/check_reel_refs.py   # доказательство референсов со стадии pre_production
python3 tools/trend_provider.py --list   # источники и состояние проверки
python3 tools/test_trend_provider.py     # двенадцать случаев слоя источников
php tools/test_ig_webhook.php      # выдача по слову
```

Первые пять стоят в `.github/workflows/checks.yml`.

## Что проверить нельзя и не пытаемся

Похож ли ролик на слайдшоу; связан ли кадр со сказанным; не выглядит ли
он массовой заготовкой; приемлемы ли руки и документы в кадре. Это
смотрит человек и смотрит на готовом mp4 — оба дефекта первых трёх партий
нашлись именно так, при зелёных текстовых проверках.
