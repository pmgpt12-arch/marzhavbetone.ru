## Неустранённые отклонения вне текущего редакционного scope

1. **P0 / ACCEPTED SOURCE DRIFT:** в ранее утверждённой статье `articles/zakazchik-ne-oplachivaet-vypolnennye-raboty.html` остаются ссылки на T1 с обещанием продажи за 990 ₽. Действующая `/products/t1-pervyy-shag-pri-neoplate.html` не имеет активного `data-sku` / `data-price`, сообщает об объединении продукта. Исправлять только отдельным адресным изменением эталонной статьи.
2. **P0 / ACCEPTED SOURCE DRIFT:** в ранее утверждённой статье `articles/ispolnitelnaya-dokumentaciya-sostav.html` остался CTA на исключённый T2 с ценой 9 900 ₽. Действующая страница T2 сообщает о включении в P4 и не предлагает покупку. Исключение из автоматического gate оформлено только для **этой неизменной эталонной страницы** с явным `KNOWN_BASELINE_WARNING`. Не считать этот warning устранённым.
3. **RELEASE METADATA:** для 32 новых редакций исторический `dateModified` в JSON-LD пока не обновлён. Установить фактическую дату публикации **на этапе релиза**, синхронизировать метаданные и проверить structured data.
4. **LEGAL / HUMAN GATE:** исправления бизнес-редакции, ссылок и расчётного примера не заменяют независимую юридическую сверку каждого правового утверждения, актуальности нормативных ссылок, сроков и применимости первичных документов. Нужна целевая содержательная приёмка перед публикацией.
5. **VISUAL GATE:** проверить мобильную и desktop-вёрстку после интеграции (изображения, отступы, заголовки, CTA), затем повторно проверить URLs и buyer path. HTTP 200 на продукт не подтверждает оплату и выдачу заказа.
