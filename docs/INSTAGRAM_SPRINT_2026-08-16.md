## Конвейер, который получился

```
сценарий (.md) → планы (shots/*.yaml) → build_footage.py → панорама 9:16
  → build_reel.py → надписи → generate_voiceover.py → голос
  → ffmpeg loudnorm → готовый mp4
```

Видеомодель не участвует. Движение даёт панорама по неподвижной обложке:
кадр 16:9 масштабируется по высоте, по нему едет окно 1080 px. Обрезка по
центру теряла бы две трети ширины вместе с композицией — у обложек
смысловой объект часто сбоку.

## Дефекты, найденные просмотром

Ни один не виден текстовой проверкой.

1. **Стиль.** `priemka.jpg` и `uderzhanie.jpg` — предметная съёмка на
   сером фоне, рядом с закатной стройкой читались как чужая вставка.
   Заменены. Правило в `style.md` исправлено: граница по кадру, а не по
   расширению файла — `.png` в `assets/` нет вовсе.
2. **Голос против экрана.** Озвучка ролика 2 говорила «объект
   приостановлен» и «если работы не выполнены», на экране — «Расторгаем»
   и «при расторжении по любому основанию». Разные условия договора.
   Сверка расшифровки ловит отсебятину модели, но не ошибку автора.

Отсюда правило: текст озвучки пишется по надписям готовой сборки.

порядок — `docs/INSTAGRAM_SETUP.md`. Пока его нет, `probe` отвечать
нечему.

`normative-checker` живут в соседнем репозитории и из сессии на одном
сайте недоступны. Оговорки расставлены, но это не замена сверке.

**Механики крючков не проверены.** У канала нет ни одной публикации,
сравнивать не с чем.
