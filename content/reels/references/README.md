# Референсы: доказательство под ролик

Ролик, написанный без разобранного чужого ролика, — угадывание. Требование
владельца 23.08.2026: до сценария на руках 3–5 реальных роликов с числами.

## Что где лежит

| путь | что это |
|---|---|
| `inbox/` | выгрузка владельца: JSON или YAML как есть, до разбора |
| `cards/` | карточки референсов, по одной на ролик-источник |
| `<NN>-<имя>.yaml` | манифест конкретного нашего ролика: кандидаты и выбор |

## Как появляется карточка

```bash
python3 tools/trend_provider.py --provider file --out content/reels/references/cards/
```

Источники объявлены в `data/social/trend-providers.yaml`. По ключу
работает прогон `.github/workflows/trends.yml`: из сессии провайдеры
закрыты выходным прокси, у раннера выход есть.

## Два вида полей, и они не смешиваются

**Замер** — `id`, `source`, `url`, `author`, `date`, `duration_sec`,
`views`, `likes`, `comments`, `thumbnail`. Приносит источник. Пустое здесь
дописывать руками нельзя: это будет число, которого никто не видел.

**Суждение** — `hook_type`, `first_seconds`, `shot_rhythm`, `avg_beat_sec`,
`video_static_ratio`, `text_style`, `voice_style`, `conflict`,
`curiosity_gap`, `escalation`, `payoff`, `cta_type`, `why_relevant`.
Ставит тот, кто ролик посмотрел, и подписывается полем `judged_by`.

Провайдер заполняет только первое. Пока второе пусто, карточка сырая, и
`tools/check_reel_refs.py` не пускает ролик дальше стадии `research`.

## Ищем механику, а не тему

Строительные ролики — не единственный источник. Механику внимания берём
из финансов, права, недвижимости, переговоров, управления и любого
контента про деньги и проблемы. Побеждает не тот, у кого больше
просмотров, а тот, чья механика переносится на нашу боль.

## Что переносим и что не копируем

Манифест обязан назвать оба списка. Переносим: структуру крючка, слом
ожидания, темп, ритм резов, чередование планов, конфликт, нарастание,
раскрытие, механику призыва.

Не копируем — и это проверяет гейт поимённо: чужой текст, бренд и автора,
лицо, конкретный сюжет, музыку без прав, видеоматериал.
