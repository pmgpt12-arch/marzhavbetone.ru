## Крючок (0–3 с)

**Текст на экран:**
```
«Делайте, потом оформим»
Это не поручение
```

**В кадре:** фраза набирается и обрывается на слове «потом». Без людей,
без объекта — только текст, чтобы первые полсекунды не тратились на
разглядывание картинки.

## Тело

**3–9 с**
```
Объём есть в бетоне.
В документах его нет
```
Кадр: свежая траншея с дополнительным слоем, рулетка на плите, пасмурный
день. Медленный наезд, надпись входит слева.

**9–17 с**
```
Спор распадается на пять вопросов
```
Кадр: пять строк появляются по одной — выполнены ли работы, вне ли они
договора, кто поручил, мог ли он обязывать, сколько это стоит. Убедительный
ответ на один вопрос не закрывает остальные.

**17–22 с**
```
Не сообщил заказчику —
лишился права требовать оплаты
```
Кадр: том закона под лампой стола прораба. Строка выделяется. Речь про
статью 743 ГК РФ.

**22–26 с**
```
Служебная записка в день обхода
С отметкой о вручении
```
Кадр: две строки списка, вторая подчёркивается.

## Оговорка

В описании публикации, обязательно:

> Материал информационный. Исход спора зависит от условий договора и
> собранных документов — по конкретному объёму нужна проверка юристом.

## Описание к публикации

Устная команда запускает людей и технику, но не запускает оплату. Договор
описывает один объём, объект содержит другой, и пока разница не описана
документом с двумя подписями, она существует только в бетоне.

Спор об оплате распадается на пять самостоятельных вопросов, и убедительный
ответ на один не закрывает остальные: выполнены ли работы, находятся ли они
за пределами договорного объёма, поручал ли их заказчик, мог ли поручавший
обязывать организацию, чем подтверждена стоимость. Комплект, где густо по
факту выполнения и пусто по полномочиям, разваливается по полномочиям.

Отдельный узел — статья 743 ГК РФ: подрядчик, обнаруживший неучтённые
работы и вызванную этим необходимость увеличить смету, обязан сообщить
заказчику, а не сообщивший лишается права требовать оплаты — кроме случая,
когда докажет необходимость немедленных действий в интересах заказчика.

Делали допработы по устной команде? Проверьте, чем подтверждён каждый из
пяти вопросов — бесплатный разбор «Допработы: что зафиксировать до начала»,
ссылка в профиле.

Материал информационный. Исход спора зависит от условий договора и
собранных документов — по конкретному объёму нужна проверка юристом.
