# Ролик 5 — тендер глазами генподрядчика

**Механика:** М4, чужая роль
**Гипотеза:** взгляд второй стороны даёт больше репостов, чем прямое предупреждение
**Длительность:** 22 секунды — та же, что у роликов 1–4
**Источник цифр:** пример из статьи — объект 40 млн ₽, план +2 млн, факт −10 млн

## Крючок (0–3 с)

**Текст на экран:**
```
Он знал, кто выиграет тендер.
До того, как его объявил
```

**В кадре:** тендерная документация на экране ноутбука, курсор на строке
критериев.

## Тело

**3–8 с**
```
«Цена — ключевой критерий, вес 70%»
Это не отбор подрядчика
```

Кадр: строка с критериями крупно.

**8–13 с**
```
Выиграет тот, кто хуже всех
посчитал свою себестоимость
```

Кадр: пять заявок стопкой, верхняя откладывается в сторону.

**13–18 с**
```
Объект 40 млн. По смете было +2 млн.
По факту −10 млн
```

Кадр: калькулятор, две суммы одна под другой.

**18–20 с**
```
Он потратил ноль
и нашёл следующего
```

Кадр: пустой объект, панорама.

## Финал (20–22 с)

**Текст на экран:**
```
Считайте до цены,
а не после тендера
```

**Голос или подпись:** Пять правил участия и что делать, если уже попали —
в разборе по ссылке в профиле.

## Оговорка

В описании публикации, обязательно:

> Материал информационный, пример условный. Оценка конкретного тендера и
> договора требует проверки документов профильным специалистом.

## Описание к публикации

Когда в тендере вес цены 70%, побеждает не самый сильный подрядчик, а тот,
кто хуже других посчитал свои расходы. Дальше договор подписывается на
этой цене, и в нём уже стоят условия, снимающие с генподрядчика риск:
допработы только по письменному согласованию, штрафы по качеству,
гарантийное удержание на несколько лет.

В примере из разбора объект на 40 млн ₽ с плановой прибылью 2 млн
закрылся убытком в 10 млн: перерасход, несогласованные допы, штрафы и
удержание, которое возвращать оказалось некому. Ни одна из этих цифр не
появилась в день подписания — они были заложены в условия тендера
заранее.

Пять правил участия в тендере и порядок действий, если договор уже
подписан, — по ссылке в профиле.
