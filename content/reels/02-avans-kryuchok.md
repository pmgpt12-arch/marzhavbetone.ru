## Крючок (0–3 с)

**Текст на экран:**
```
Аванс 5 миллионов —
это не ваши деньги
```

**В кадре:** банковское уведомление о поступлении, сумма крупно. Резкий
рез на слове «не».

## Тело

**3–8 с**
```
Вы купили материал, вывели бригаду,
оплатили аренду
```
Кадр: техника на объекте, быстрая склейка из трёх планов.

**8–13 с**
```
Через два месяца письмо:
«Расторгаем. Верните аванс за 5 дней»
```
Кадр: письмо на экране телефона.

**13–17 с**
```
В договоре: аванс возвращается
при любом расторжении
```
Кадр: строка договора, обводится.

**17–19 с**
```
Минус 5 миллионов.
Он потратил ноль
```
Кадр: пустой объект, панорама.

## Финал (19–22 с)

**Текст на экран:**
```
Проверьте три условия
Ссылка в профиле
```

**Голос или подпись:** Аванс должен быть оплатой, а не займом. Требуют
вернуть аванс — проверьте три условия договора, ссылка в профиле.

Три секунды под кадр, а не две: карточка действия должна успеть
прочитаться. Время взято у предыдущего кадра, длительность ролика не
изменилась.

В описании публикации, обязательно:

> Материал информационный. Возможность оспорить расторжение и удержать
> аванс зависит от условий договора — нужна проверка документов юристом.

## Описание к публикации

Авансовая ловушка собирается из трёх деталей, каждая из которых по
отдельности выглядит безобидно: аванс 20–30%, условие о возврате в полном
объёме при расторжении по любому основанию и право генподрядчика
расторгнуть договор без объяснения причин.

Дальше механика простая: вы вкладываете аванс в объект, вас выводят с
объекта, аванс вы возвращаете. Генподрядчик потратил ноль и получил
готовый этап работ.

Поэтому опытные субподрядчики иногда сознательно отказываются от аванса —
чтобы получить договор, из которого их нельзя выкинуть без оснований.
Пять правил работы с авансом и формулировки для договора — по ссылке в
профиле.
