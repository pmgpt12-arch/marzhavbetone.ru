# Ролик 6 — проверка генподрядчика до договора

**Механика:** М5, обратный отсчёт до потери
**Гипотеза:** срок, после которого действие невозможно, даёт больше переходов, чем польза без срока
**Длительность:** 22 секунды — та же, что у роликов 1–5
**Источник цифр:** статья — проверка по пяти маркерам занимает около тридцати минут

## Крючок (0–3 с)

**Текст на экран:**
```
Проверить его можно
только до подписания
```

**В кадре:** договор и ручка, рука тянется к подписи и останавливается.

## Тело

**3–8 с**
```
После — вы просто
один из кредиторов в очереди
```

Кадр: список требований на экране, курсор уходит вниз списка.

**8–13 с**
```
Картотека арбитражных дел:
больше пяти исков о взыскании за год
```

Кадр: экран с результатами поиска по компании.

**13–18 с**
```
ЕГРЮЛ: директора сменили полгода назад
и он из другого региона
```

Кадр: выписка, строка с датой изменения.

**18–20 с**
```
Тридцать минут в открытых источниках
```

Кадр: часы, стрелка проходит полкруга.

## Финал (20–22 с)

**Текст на экран:**
```
Сработали два маркера —
меняйте условия оплаты
```

**Голос или подпись:** Пять маркеров с адресами источников — в разборе по
ссылке в профиле.

## Оговорка

В описании публикации, обязательно:

> Материал информационный. Проверка по открытым источникам не даёт
> гарантий: оценка конкретного контрагента и условий договора требует
> анализа документов профильным специалистом.

## Описание к публикации

Банкротство генподрядчика редко становится неожиданностью — маркеры видны
в открытых источниках за год до того, как вы подпишете первый акт.

Смотреть нужно четыре вещи в документах и одну в поведении: рост исков о
взыскании за последние 12–18 месяцев, смену директора на человека, не
связанного со стройкой, появление «зеркальной» компании с тем же
учредителем, разрыв между растущей выручкой и нулевой прибылью — и
спешку с подписанием в сочетании с отказом менять формулировки.

Проверка занимает около тридцати минут и почти никем не делается. Она не
даёт гарантий, но переводит решение из области надежды в область расчёта:
если сработали хотя бы два маркера, стоит требовать аванс, сокращать
этапы закрытия и не выводить на объект технику, которую тяжело забрать.

Пять маркеров с адресами источников — по ссылке в профиле.
