## На какие интенты отвечают существующие страницы

Кластер уже несёт носителей — keyword_map их не увидел, потому что целевые
URL точных строк метят в незаведённый `/proverki/`, а у широких URL пуст:

1. `/articles/raboty-ne-prinyaty.html` — «работы выполнены, но не
   приняты»: meta description дословно «заказчик не подписывает приёмку и
   КС-2»; h2 — не ждать молча → работать с замечаниями как с реестром →
   мотивированный отказ: что делает его мотивированным → односторонний
   акт → доказуемая хронология → порядок при затянутой приёмке → где
   начинается юрист. Ссылки на товары: P3 ×2, T1. Вх. из разборов 7.
2. `/articles/podpisannaya-ks2-ne-znachit-chto-zaplatyat.html` — стадия
   после подписания: 4 ловушки договора, 4 ошибки субподрядчика, алгоритм
   взыскания по КС-2 («КС-2» ×28, «КС-3» ×5). Ссылки: P1 ×2. Вх. 18 —
   хаб темы КС на сайте.
3. `/materialy/vozvrat-ks.html` — бесплатный материал «КС без возврата:
   проверочный лист комплекта» («проверк» ×4), ссылка на P3. Вход в
   воронку P3.
4. Товарные: `/products/p3-shablony-ks2-ks3.html` (проверочный лист,
   алгоритм проверки перед сдачей, типовые ошибки, письмо о недостатках) и
   `/products/p1-oplata-po-ks2.html` (шаблоны КС-2/КС-3, акт приёмки,
   **реестр замечаний**, претензия, иск, словарь полей).

Чего ни одна страница не несёт: отдельного ответа на «проверка КС-2» в
title/h1 — «проверк» в статьях 2–4 раза по телу, страницы под интент
самопроверки перед сдачей нет. Это единственный разрыв кластера.

## Подтверждённые create в порядке производства

Один.

**1. «Проверка КС-2 перед сдачей: что ищет заказчик, чтобы вернуть акт»**

- Запросы: «проверка актов кс 2» (137) + «проверка кс 2 кс 3» (127) +
  «проверка работ кс 2» (112) + «проверка форм кс 2» (75) = 451 точной в
  месяц по четырём хвостам одного интента — вдвое больше подтверждённого
  create Удержаний (236).
- Носитель — «проверка актов кс 2»; title несёт «проверка КС-2»; рабочий
  URL — `/articles/proverka-ks-2-pered-sdachey.html` (раздел — решение
  владельца: семантика планировала `/proverki/`, которого на сайте нет,
  а все 36 разборов живут в `/articles/`).
- О чём страница, и чем отличима: самопроверка комплекта КС-2/КС-3 глазами
  заказчика до передачи — что сверяет технадзор, из-за чего акт
  возвращают, как проверить объёмы против журнала, что приложить. П — про
  «подписали и не платят», Р — про «не принимают», новая — про «ещё не
  отдал»: три стадии, три страницы, пересечения нет. От create Удержаний
  («Гарантийное удержание в КС-2 и КС-3») отлична предметом: там — как
  показать удержание в формах, здесь — как сдать комплект с первой
  попытки; второй create по тому интенту отсюда не ставится, при
  публикации обеих — взаимные ссылки.
- Входящие ссылки: из П (хаб, 18 вх / 5 исх), из Р (стадия следующая),
  из pyat-dokazatelstv-vypolneniya (12 вх) — кандидаты для
  `marzha-seo-implementer`.
- Продукт в конце: **P3** (1990 ₽) — страница пересказывает его продающую

- Уверенность: средняя. Риск: направление проверяющего не разложено —

## Владельцу

Предложения, не действия. Файлы, кроме этого отчёта, не менялись.

**1. Свернуть план четырёх страниц `/proverki/` в одну** (строки ID 60,
62, 64, 71: целевые URL четырёх отдельных коммерческих страниц под одну
лемму). Предлагаемая правка — всем четырём один целевой URL create №1;
раздел (`/articles/` или заведение `/proverki/`) — ваше решение, моя
рекомендация `/articles/`: раздел под один URL не окупает заведение.
Цена: правка CSV; выгода — минус три каннибализирующие страницы из плана
и минус 4 из 12 строк «/proverki/» в РЕШЕНИЕ `check_seo.py`.

**2. Запустить производство create №1** — единственный вход конвейера по
этому кластеру, спрос 451 точной подтверждён. Цена: одна статья
`marzha-content` + ссылки `marzha-seo-implementer`; проверка —
`check_seo.py` и `link_audit.py` после публикации.

**3. Привязать целевые URL трёх широких строк к существующей статье Р**
(ID 592 «заказчик не подписывает кс-2», 593 «отказ в приёмке работ»,
594 «реестр замечаний» → `/articles/raboty-ne-prinyaty.html`; сейчас URL
пуст, статус «Замерено»). По ID 590–591 (леммы-гиганты) — URL оставить
пустым со статусом отказа: привязка 2 млн широкой к странице исказит
любой будущий счёт покрытия. Цена: правка CSV.

**4. Снять 50 шаблонных заготовок кластера** (ID 409–458) — CSV сам
называет их не поисковыми запросами, но их URL продолжают числиться в
221 строке «/baza-znanii/» из `check_seo.py`. Все 50 — грани интентов,
уже получивших решение. Рекомендую снять без замера; замерять шаблонные
хвосты прогоном wordstat.yml смысла нет — это не формулировки людей.

**5. Связать T3 со страницей его темы.** Наблюдение: Р несёт h2
«Односторонний акт: когда он работает и чего не закрывает»
(«односторонн» ×6), а ссылки на T3 (990 ₽) на странице нет — grep по
файлу: только P3 и T1; на T3 ссылаются лишь pretenziya-za-chuzhuyu-
kommunalku и materialy/uderzhaniya. Читатель, дочитавший до
одностороннего акта, — покупатель T3, и путь оборван. Цена: одна ссылка
исполнителем `marzha-seo-implementer`. Рекомендую первым из пяти: это
единственный найденный обрыв на действующем носителе кластера №3 по
близости к деньгам.

**Чего не предлагается:** страниц под «кс-2», «кс-3» и «реестр замечаний»
— первые две леммы не несут отличимого вопроса, третья при нулевой
уточнённой точной частоте обслужена разделом Р и артефактом в P1.
